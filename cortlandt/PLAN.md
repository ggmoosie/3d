# Cortlandt Station — Blender → UE5 build plan

Source of truth for the hub level of LootNShoot (`/Game/Maps/CortlandtStation`).
Layout design: see **LAYOUT.md** (v3, "The Arcade").
Everything is generated by code. Re-running `run.py` rebuilds the `.blend`, every mesh, and the
placement manifest from scratch. Nothing is hand-placed, so nothing drifts.

## Architecture (one-directional deps)

```
core/      pure python, no bpy.  dims, registries, layout math → a Level description
  spec.py        every number and registry (levels, rooms, stores, materials, counts)
  geom.py        Box / Hull / slabs-with-holes / walls-with-openings / stairs
  kit.py         blockout kit pieces (name → local geometry)        ← art passes replace these
  layout_*.py    platform / mezzanine / street → parts, instances, markers, lights
bl/        bpy only. turns a Level into Blender objects, collisions, previews
exporter   one FBX per unique mesh + layout.json (UE-space transforms)
ue/        UE editor python: import FBXs → enable Nanite → spawn actors/markers/lights
tests/     pure tests on core (counts, stair math, no-bpy import rule)
```

**Contract = mesh names + layout.json.** An art pass swaps `SM_Turnstile`'s geometry; every
placement stays valid. Variation is data: storefronts, shops and commons zones are registry rows.

## UE conventions

| Thing | Rule |
|---|---|
| Units | Blender metres → UE cm (FBX default; 1 m = 100 uu). Platform top = z 0, mezz z 520, street z 1000 |
| Axes | UE = (x, −y, z)·100, yaw = −rz. Placements are yaw-only by design |
| Names | `SM_` meshes, `M_` material slots, `UCX_SM_Name_##` convex collision in the same FBX |
| Collision | Simple UCX everywhere. Stairs collide as smooth ramps (no step jitter) |
| Rendering | Nanite on all opaque meshes, Lumen GI. No lightmap UVs needed. UV0 = world-scale box UV, 1 tile per m |
| Shells vs kit | Architecture = unique shell meshes per zone; anything repeated = instanced kit mesh |
| Gameplay | Markers → `TargetPoint` actors tagged `Cortlandt.<Kind>`; PlayerStarts in bunks |
| Lights | Every light is spawned at a fixture from the manifest (no floating lights) |

## Real-world dims used

- Platform level: island platform 70 × 9 m, edge 1.1 m above trackbed, two 4.5 m trackways, ceiling 4.3 m
- Columns: I-beams every 15 ft (4.572 m), two rows at y ±3.3
- Stairs: 0.28 m treads, mid landing 1.5 m. Street→mezz 27 risers (17.8 cm), mezz→platform 29 risers (17.9 cm)
- Mezzanine: 84 × 24 m arcade, 8 m concourse over the platform, clear height 3.6 m. Street slab 1.2 m
- Street: avenue 12 m curb to curb, 4.5 m sidewalks; cross streets 10 m + 4 m; blocks ~82 m between intersections
- Train: R142-class cars 15.5 × 2.7 m, floor flush with platform; 4 live cars on Track A, 3 derelicts + test range on Track B
